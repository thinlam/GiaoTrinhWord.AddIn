# 📘 Giáo Trình Microsoft Word

**Giáo Trình Microsoft Word** là tiện ích mở rộng dành cho Microsoft Word trên Windows, cung cấp hệ thống bài học từ cơ bản đến nâng cao ngay bên trong Word.

Sau khi cài đặt, một tab **GIÁO TRÌNH** sẽ xuất hiện trực tiếp trên Microsoft Word.

---

## ✨ Tính năng

- 📚 Giáo trình Microsoft Word từ cơ bản đến nâng cao
- 🔎 Tìm kiếm nhanh nội dung bài học
- 🧭 Phân loại bài học theo cấp độ
- 🖥️ Hiển thị giáo trình trực tiếp bên trong Microsoft Word
- 🎓 Tab `GIÁO TRÌNH` riêng trên Ribbon
- 🌐 Nội dung được cập nhật trực tuyến
- ⚡ Không cần cài lại khi nội dung giáo trình được cập nhật

---

## 🖥️ Yêu cầu hệ thống

- Windows 10 hoặc Windows 11
- Microsoft Word Desktop
- Kết nối Internet
- Microsoft Edge WebView2 Runtime
- .NET Framework / VSTO Runtime

> Hiện tại tiện ích dành cho **Microsoft Word Desktop trên Windows**.

# 🚀 Cài đặt bằng EXE

### Cách khuyến nghị

1. Download:

   `GiaoTrinhWord-Setup-v1.0.0.exe`

2. Double-click file vừa tải.

3. Chọn **Install**.

4. Sau khi cài đặt hoàn tất, mở Microsoft Word.

5. Trên Ribbon sẽ xuất hiện:

   **GIÁO TRÌNH**

6. Chọn:

   **GIÁO TRÌNH → Mở Giáo Trình**

Giáo trình sẽ xuất hiện ở panel bên phải Microsoft Word.

---

# 📦 Cài đặt bằng ZIP

Bản ZIP được cung cấp cho trường hợp cần cài đặt thủ công.

1. Download:

   `GiaoTrinhWord-Publish-v1.0.0.zip`

2. Giải nén file ZIP.

3. Mở thư mục vừa giải nén.

4. Chạy:

   `setup.exe`

5. Hoàn tất quá trình cài đặt.

6. Mở lại Microsoft Word.
